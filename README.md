# SMS_PYTHON – School Management System (Django)

This project is a School Management System built with Django, Python, and HTML/CSS.  
I created it as a learning exercise with guidance from AI tools and online resources.  
It helped me understand backend development, authentication, templates, and interactive UI design.

## Features

- Separate login systems for admins, teachers, and students
- Profile photos for students and teachers
- Gradient UI and hover animations
- Attendance charts and grade charts
- Role-based dashboards and permissions

## Tech Stack

- Python 3
- Django
- HTML / CSS
- SQLite (default Django database)
